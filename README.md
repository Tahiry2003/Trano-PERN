# 🏠 Trano-PERN

**Trano** is a modern real estate rental platform designed to simplify the process of finding, publishing, and managing rental properties.

The project is built with the **PERN Stack** (PostgreSQL, Express, React, Node.js) and styled with Tailwind CSS 3.4.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS 3.4
- React Router
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
- Bcrypt

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/TON_USERNAME/Trano-PERN.git

cd Trano-PERN
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Install backend dependencies

```bash
cd ../backend
npm install
```

### 4. Configure environment variables

Create a `.env` file in the backend directory.

Configure your PostgreSQL connection and application environment variables according to your backend configuration.

Never commit your `.env` file.

### 5. Run the backend

```bash
cd backend
npm run dev
```

### 6. Run the frontend

Open another terminal:

```bash
cd frontend
npm run dev
```
